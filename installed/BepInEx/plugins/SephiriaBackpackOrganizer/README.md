# 背包整理 2.5.4

快捷键 F8。中键：默认 → max → ↑ → 默认；Ctrl+中键：默认 → - → ↓ → 默认。日志收藏默认 max，手动设置优先。

max 优先满级；↑ 尽量提高等级；- 保持启用；↓ 尽量负等级。完成仅提示“整理完成”。移除首次固定 3 秒等待，加入组合整体移动、局部重排和分层目标，补齐克里顿的印章优先级 2。

沿用插件 ID com.sephiria.backpack-organizer，管理器可直接更新旧版。保留旧配置。若曾装过独立 .own 开发版，请先移走其 DLL，避免重复处理中键。

Release 编译及 2249 条隔离断言通过，游戏内与联机尚待玩家验收；没有证明搜索结果全局最优，也未完成同背包新旧性能对比。
