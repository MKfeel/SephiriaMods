# 流派智能背包整理 3.0.5

3.0.5 继续优化评分计算，保持 F8、完整的 8 起点搜索，以及 3.0.4 的同分无损属性提升。没有改变收益权重、随机提案次序、候选数量或最终目标。实际效果以游戏内整理为准。

本版对固定背包预先建立属性与效果索引，按等级缓存原生整数属性贡献；候选变化时增量更新这些贡献。小数属性或超出安全整数求和范围的输入使用完整累加路径；条件效果、外部加成和属性转化保持原来的计算次序。可证明等价的纯属性组合共享战斗评分，流派核心目标、直接引用的特殊神器及所有手动标记仍保留独立等级。

搜索中复用只供内部计算的物品记录，精简元素换算和重复目标计算。违反白纸、行锁等硬约束的候选在战斗评分前拒绝；空格互换或旋转未变化时复用当前评分。所有提案、随机数消耗和搜索步数照常保留，最终布局仍完整重算属性和效果。临时共鸣石规划及外部提案接口仍沿用各自目标与完整约束。

性能与结果对照扩展到 **12 份背包：3 份真实游戏快照、9 份合成样本**，覆盖 18–60 格、9–50 件物品，以及物理、等离子、行星、同伴乌云、双发雷法、融合太阳剑、岩象、腰带/和谐、指针链、白纸、手动标记、行锁和固定格。合成样本由发布的 3.0.4 模型生成原生格式输入，并明确标记来源；不等同于更多实际游戏存档。

保留 3.0.4 对同分时“少移动”挡住免费属性提升的修复。主搜索之后增加最多 6 轮局部检查：主评分和手动目标不变，且所有受保护效果均无损失时，优先接受属性提升，最后才考虑少移动。保留 3.0.3 的缓存提速和 3.0.2 的沉闷的共鸣石成长准备。

无损等级提升仅开放给已核对原生实现的纯属性类 `Charm_StatusInstance`、`Charm_HomingMagic`；逐项比较防御、闪避、回蓝和吸蓝，不给神器加主观权重。其他原生属性、追踪等开关、动态神器和石板的位置/等级、类别、相邻联动及各输出通道都受到保护；纯属性神器也不能靠降低另一件神器的有效等级或属性换收益。未证明方向的阈值、转化和动态效果保持原搜索规则。C# 应用前使用同一份属性及约束证据复核，仅允许在主目标相同时越过“少移动”；旧 2.5.5 路径不变。

此前 3.0.3 对完整安装包做三轮交替回放，以含进程启动的总耗时中位数比较：31 件真实背包从 3.0.2 的 5.20 秒降到 2.65 秒（减少 49%），25 件背包从 3.89 秒降到 2.22 秒（减少 43%）。前者搜索 145,756 个候选，后者 145,437 个，均完成 8 个起点，最终格位、旋转和目标分完全一致。耗时是历史离线回放测量，不是游戏内耗时保证。

保留的提速将不随摆放变化的连击贡献和地块输入预先计算，仅重建白纸、指针和按行变化的类别；按有效等级及实际相邻关系合并等价战斗状态。原始等级对手动标记、和谐及指针对应效果仍单独保留。缓存键使用完整数值元组，大数或小数走精确后备路径；两个有界缓存使用循环队列淘汰。候选评分省去只供最终诊断使用的数据，最后返回结果时仍完整重算。没有调整收益权重、随机提案顺序或主搜索起点/步数。

保留 **F8** 和现有箭头标记。按 F8 后读取本地玩家当前武器实体、类型、形态、主背包、强化、原生石板查询及铭刻矩阵；根据武器兼容性、构筑核心组件覆盖与连击数量选择模型。共有 59 个攻略模型分支。相近分支会退回机制家族或基础模型并在日志中列出候选，识别置信分级不是统计概率。

## 共鸣石成长准备

背包存在带成长任务的沉闷的共鸣石时，读取它的原生目标（当前为 140 移速）及成长奖励。模型按实际移动倍率、当前减速、神器等级曲线和连击加成寻找能达标且让共鸣石启用的布局。已有 140 移速时直接等待成长；上界不足时直接跳过临时搜索。

找到布局后先通过原生交换和旋转凑移速，等待游戏将沉闷的共鸣石原地替换为共鸣石。确认新神器及映射同步后，恢复整理前的格位，重新采集新神器和原生属性，再做完整的流派收益整理。全过程保留手动标记、白纸、指针和行锁约束；每次 F8 最多尝试一次成长，不修改任务进度、移速或物品 ID。

搜索没找到可行布局时照常整理；等待超时（至少 2 秒，受原有服务器确认超时设置影响）则恢复格位并继续普通整理。搜索属于启发式，未找到不等于数学上证明无法凑到 140。布局外的短暂增益可能在执行时消失，是否成长以游戏实际替换物品为准。3.0.2 起的新快照包含完整移速字段，更早快照回放会跳过成长准备。

## 安装与回退

完全退出游戏后，在完整解压目录运行 `Install.ps1`。默认游戏位置为 `E:\steam\steamapps\common\Sephiria`，可通过 `-GameDirectory` 修改。安装前自动备份被替换的 DLL 和模型文件，完成后输出 `rollback.json` 路径。回退使用 `Rollback.ps1 -ManifestPath <该路径>`。不要只复制 DLL：模型代码、数据和 Node.js 运行时均需保留。

安装包自带 Node.js 22.20.0 和许可证，无需联网或安装其他运行时。F8 每次在隐藏、低优先级子进程运行纯数据搜索，结束后退出；主线程仍通过游戏原生交换、旋转和服务器确认完成整理。没有常驻视频识别、HTTP 服务或额外热键。

## 模型与约束

- 与 `backpack-simulator` 共用 `model.js`、`mechanics.js`、`builds.js`、`runtime-model.js` 及 `resonance-model.js`。没有额外的“某神器很强”物品权重。
- 箭头目标按既有顺序比较：双上启用数、缺级、缺级均衡、单下启用、单上有效等级、双下负等级、普通代理分。全部相同时，检查可证明的无损属性提升，再考虑少移动。普通分再高也不能抵消前一层的下降。
- 白纸已有完整连击、金色针已有目标、显式行锁都是候选合法性约束。神秘连击数量保持不变，以保留当前原生固定铭刻；下一次 F8 重新采集。
- 石板使用实际实例的原生解析结果；越界条件保留为未满足。地块从原生矩阵扣除当前物品影响，不把已有加成算两遍。支持的原生属性按原布局扣除模型贡献后作为固定残差加入。
- 搜索期间换武器、改物品、拖拽或改箭头会取消旧搜索，重新等待稳定快照。应用前复查快照，应用后复查实际等级、启用状态及白纸；同步超时或不一致走原有停止/回退流程。
- `SearchTimeBudgetMs=0` 保留普通整理完整的 8 起点 × 18,000 步和最多 64 次局部改进；正预算在时间达到后保留最佳合法结果。进程启动及快照准备不计入搜索预算。临时移速搜索找到可行解即可结束，不减少后续普通整理的搜索。

## 设置与复现

配置仍为 `BepInEx/config/com.sephiria.backpack-organizer.cfg`：

```ini
[BuildModel]
Enabled = true
Profile = auto
ExportLastSnapshot = true
```

`Profile` 可填 `judge`、`sun`、`planet`、`fusion-tri` 等模拟器流派 ID；不兼容的指定武器流派会拒绝应用。`Enabled=false` 使用此前 2.5.5 搜索路径。成功计算后仅覆盖保存最近的 `model/snapshots/last-input.json`、`last-result.json`。本地命令行回放：

```powershell
Get-Content -Raw -Encoding utf8 model/snapshots/last-input.json | & model/runtime/node.exe model/worker.cjs
```

请在完整包根目录执行。也可将输入快照导入离线 `game-replay.html` 可视化比较。重开游戏后，在背包稳定时按 F8，结合日志核对武器 ID、识别候选与最终等级。日志包含准备/成长规划/搜索耗时、成长或跳过原因、缓存命中、防御/全伤与 MP 供需；3.0.4 增加“同分无损属性提升”记录，列出实际移动、前后等级和属性、检查数量及耗时。结果快照保存复核证据、输出通道和未覆盖的动态效果。

3.0.0 旧快照的部分原生属性字段错误，无法从旧文件恢复这些属性的外部加成。回放时会明确提示，并只使用已建模背包贡献；用 3.0.1 重新按 F8 后，新快照的 `nativeStatsSchema=2` 会保存正确原生属性。

## 验证边界

3.0.5 验证包括 3,015 项增量评分与回退路径检查、105,860 项编译评分对照、59 分支主搜索与无损检查对照（531 项）、313 项运行时检查、42,532 项运行时回归、5,656 项模型/原生石板查询检查、68 项吊坠同分修复回归及 20 项共鸣石规划检查。另对 12 份背包完整搜索做独立进程对照，逐项核对最终格位、旋转、评分、等级、启用、属性、输出、MP 供需、联动与无损增益证据。完整安装包还验证原生格式快照回放、C# 验收及安装回退。**3.0.5 尚未进行游戏内验收。** 共鸣石检查不等同于游戏内成长流程验收。代理输出不是实战 DPS；触发频率、敌人条件与部分武器机制仍采用攻略近似。

游戏程序集哈希变化时会拒绝使用过期数据。未知物品、当前无法一致重建的启用/等级、重复唯一神器、递归白纸和排列奖励暂时保留原布局并在日志说明。运行时修改游戏规则的其他 Mod 尚未全面验证。

Eden_T 视频收益实验仍单独保留，未装入本版 F8：现有一类构筑的部分可观察属性训练对 5 个、留出对 2 个，完整背包状态偏好对为 0。本版不宣称通过视频训练获得实战收益提升。
