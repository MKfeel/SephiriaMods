# 流派智能背包整理 3.0.1

修复背包包含模组物品时因“物品类型未建模”而整理失败的问题。按 F8 后，原版物品继续使用流派模型；模型表之外的物品、类型被模组替换的物品及外部模组定义的类型，不计算其自定义属性、伤害或动态效果，保留物品实例、占格和玩家的手动标记。

模组神器默认不因自身等级或效果获得流派收益分。需要优先安排时，在背包图标上使用已有标记：

| 操作 | 标记 | 目标 |
| --- | --- | --- |
| 鼠标中键循环 | ↑ | 提高有效等级 |
| 再按鼠标中键 | ↑↑ | 优先启用并达到满级 |
| Ctrl + 鼠标中键循环 | ↓ | 保持启用，少占额外等级 |
| 再按 Ctrl + 鼠标中键 | ↓↓ | 放到负等级 |

继续循环可清除标记。原来的收藏映射和标记顺序保留。模组物品仍参与通用位置条件、石板作用、连击类别、白纸/指针绑定及行锁；模组自己的额外激活条件、等级变化和效果不作流派预测。无法识别的自定义位置条件沿用采集时的启用状态，玩家可结合物品说明选择标记。

模组物品的原生当前属性保留为固定背景值，不把其随摆放变化的自定义效果当作收益。原版物品仍进行原生等级、启用状态及连击数量校验。日志会列出跳过建模的物品编号和类型，结果快照的 ignoredItems 保存同样记录。

## 安装与回退

完全退出游戏后，将安装包中的 BepInEx 文件夹复制到游戏根目录，合并目录并覆盖同名文件。也可在模组管理器中导入此 ZIP；根目录的 mod-manifest.json 包含插件身份、版本、安装目标及逐文件 SHA-256。

DLL、README.md、LICENSE、完整 model/ 和 Node.js 运行时均位于 BepInEx/plugins/SephiriaBackpackOrganizer/，需一起安装。手动覆盖前可备份这个插件目录，回退时恢复备份；通过管理器安装可使用管理器的操作回退。安装包不包含玩家配置。

配置文件仍为 BepInEx/config/com.sephiria.backpack-organizer.cfg。保持 [BuildModel] Enabled = true 即可使用本次兼容修复；设置为 false 时走原来的整理算法。
