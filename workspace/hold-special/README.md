# 按住特殊攻击 · Sephiria Hold Special 1.0.1

使用游戏现有的特殊攻击键，按住后按武器机制持续施放，松开停止追加攻击。支持游戏内键位重绑及手柄，不绑定固定鼠标键。原生单击行为保留。

**“放血”和“重新组装”完全保留原本操作逻辑：不自动释放、不自动松键、不自动重复。**

| 武器／机制 | 按住后的行为 |
| --- | --- |
| 大剑蓄力 | 等待游戏判定蓄满后自动松键出招，动作结束再蓄下一次；快蓄、长蓄沿用原生计时 |
| 大剑连续旋风 | 在原生后续旋风窗口继续输入；连段和耗蓝由游戏决定 |
| 大剑：放血／重新组装 | 完全保留原生手动操作，不纳入自动释放 |
| 匕首 | 动作结束后再次请求特殊攻击；招架、狂怒、飞刀等仍由当前武器和资源决定 |
| 长棍／长枪 | 动作结束后继续特殊攻击，保留武器附加动作、叠层和资源判断 |
| 弩：特殊射击 | 动作结束后继续射击 |
| 弩：快速装填 | 弹药未满且未在装填时重试 |
| 弩：冰增益 | 按游戏原生冷却重试 |
| 弩：压缩弹 | 尚未压缩且弹匣大于一发时触发；已有压缩弹时等待其消耗 |
| 弩：机枪 | 保留原生按住预热和持续射击，不反复松键打断 |
| 太刀：纳刀 | 保留首次纳刀／出鞘切换，不连点翻转架势；拔刀仍使用原生普攻操作 |
| 太刀：弹反／云斩 | 空闲时继续请求；原生资源和动画限制保留 |
| 太刀：增益 | 由原生增益状态和资源决定何时再次生效 |
| 剑盾 | **单独按住特殊攻击仍是防御；同时按住普攻和特殊攻击才连续横扫。**后续自动横扫遇到蓄力型时等蓄满；首次手动普攻按原生时机执行 |
| 没有独立特殊攻击的武器 | 不凭空添加招式，保持游戏原有行为 |

角色死亡、菜单接管、窗口失焦、动作键停用、切换武器或把特殊攻击槽换成法术时停止追加输入。恢复后重新按键开始；已开始的攻击仍按游戏自身流程结束。施法模式下不自动执行剑盾组合。

不改攻速、伤害、耗蓝、弹药、冷却、掉落或存档；全部通过原生玩家输入方法触发。不会自动开火消耗压缩弹，不会把太刀纳刀变成无条件拔刀连斩。

## 安装和配置

退出游戏，将压缩包中的 `BepInEx` 文件夹合并到游戏根目录。DLL 路径为 `BepInEx/plugins/SephiriaHoldSpecial/SephiriaHoldSpecial.dll`。

首次启动后配置在 `BepInEx/config/feel.sephiria.holdspecial.cfg`：

- `Enabled = true`：总开关。
- `RetryInterval = 0.12`：最小重试间隔（秒）；不解除游戏自身动作限制。

只扩展当前绑定在特殊攻击槽的武器特殊攻击；该槽替换为法术时不会自动施法。移除上述插件文件夹即可卸载。

## 验证范围

依据 2026-09-22 本机游戏程序集分析；精确 SHA-256 记录在 `manifest.json`。检查了全部 7 个覆盖 `SubAttackButtonDown` 的武器类及其变体。

已做 Release 编译、自动输入生命周期测试和当前游戏接口／原生调用路径检查。**未启动游戏做实战验证**，不能把编译和文件校验当作游戏内成功证据。

实现使用本地玩家的原生网络命令；单人、房主及联机客机均需游戏内验证。未使用的 `WeaponSimple_Katana_New` 原型只在本地服务端读取其接招窗口，客机不扩展该原型。

建议实际验证：大剑连续三次蓄满；快蓄／长蓄；放血和重新组装按住不自动释放、松键依原生逻辑处理，效果结束不自动重放；弩五种模式；匕首及长棍；太刀纳刀不反复切换；剑盾仅防御及双键横扫；最后在按住期间开菜单、切换窗口和武器，确认重新按键后再开始。资源不足时应保留原生失败行为。
